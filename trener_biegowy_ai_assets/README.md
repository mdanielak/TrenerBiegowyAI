# Trener Biegowy AI — pakiet grafik

Łącznie: 104 osobnych plików PNG. Ikony i elementy UI mają przezroczyste tło.

Struktura:
- 00_mockups — cztery osobne makiety ekranów
- 01_navigation — nawigacja aplikacji
- 02_health_status — sen, HRV, tętno, stres, statusy
- 03_activity — bieganie, spacer, regeneracja, trasa
- 04_ui_readiness — wskaźniki gotowości
- 05_ui_charts — wykresy i mapa trasy
- 06_ui_badges — etykiety stanu i trendu
- 07_ui_icons — drobne ikony interfejsu
- 08_ui_cards — gotowe kafelki metryk
- 09_illustrations — większe ilustracje
- 10_sports_weather — sport i pogoda
- source_sheets — oryginalne plansze źródłowe

Dodatkowe assety (v2):
- readiness — osobne wskaźniki gotowości 1–10 + wariant brak danych
- branding — osobne warianty logo i znaku aplikacji
- `_sheet_readiness_full.png`, `_sheet_branding_full.png` — pełne arkusze źródłowe

Pliki v2 to wycięcia z wygenerowanych plansz assetów i również mają przezroczyste tło.

## Generowanie i podmiana grafik

Nowe grafiki powstają skryptem `scripts/generate_art.py` (OpenAI Images, klucz w `OPENAI_API_KEY` w środowisku albo w `.env`). Skrypt wybiera najnowszy model `gpt-image-*`, który obsługuje przezroczyste tło, i zapisuje wynik do `_generated/<przebieg>/` wraz z arkuszem `sheet.html` do przeglądu. W promptach nie ma danych biegacza.

1. `python scripts/generate_art.py --list` — lista grafik i ich docelowych ścieżek.
2. `python scripts/generate_art.py` (albo `--only <klucze> --run <katalog>`, żeby poprawić pojedyncze).
3. Przejrzyj `sheet.html`, potem `python scripts/generate_art.py --promote <katalog>` kopiuje wybrane pliki do `_originals/`.
4. `python scripts/rescale_assets.py --write` tworzy pliki prezentacyjne w rozmiarach z szablonów (2× rozmiaru wyświetlania).

Katalog `_generated/` jest ignorowany przez Git.
